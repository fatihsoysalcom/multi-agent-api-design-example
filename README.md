# Multi Agent API Design Example

This example demonstrates a multi-agent AI system where specialized agents collaborate to complete a complex task. An Architect agent designs a plan, a Developer agent implements sub-tasks, and a Tester agent verifies solutions. A Project Manager agent orchestrates the entire workflow, showcasing how communication and specialization overcome the limitations of a single, monolithic approach.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal in the same directory and run: `python main.py`
